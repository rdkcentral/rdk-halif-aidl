# Video Decoder HAL

AIDL interface for the RDK video decoder HAL, in
[current/com/rdk/hal/videodecoder/](current/com/rdk/hal/videodecoder/).

The specification is [Video Decoder](current/docs/video_decoder.md). End-of-stream
signalling, including a `flush()` that interrupts a pending end-of-stream, is
in its [End of Stream Signalling](current/docs/video_decoder.md#end-of-stream-signalling)
section.
